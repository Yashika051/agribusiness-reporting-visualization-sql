# 🌾 Agribusiness Reporting & Visualization

### Yuva Intern · SQL Data Analyst - Agribusiness · Week 4

A business reporting project that turns **SQL-based agribusiness analysis into clear visual insights and practical recommendations** for non-technical stakeholders.

---

## 📌 About the Project

Agribusiness operations generate data across crops, farms, seasons, production and operational costs. Raw SQL results are useful for analysis, but they become much more valuable when they can be communicated clearly to business stakeholders.

This project represents the **final reporting and visualization stage** of the agribusiness analysis.

The work brings together findings from the previous stages and presents them through:

* 🗃️ SQL-based data extraction
* 📊 Business-focused visualizations
* 📋 Result tables
* 💡 Data-driven insights
* 🎯 Strategic recommendations

The goal is to make the analysis understandable without requiring stakeholders to read or understand the underlying SQL.

---

## 📊 Key Findings

| Metric                            | Finding                             |
| --------------------------------- | ----------------------------------- |
| 🥇 Highest total production       | **Wheat · 1,175 units**             |
| 🌱 Highest yield per acre         | **Tomato · 9.00 units/acre**        |
| 🚜 Highest farm production        | **Sunrise Agro Farm · 1,340 units** |
| 📅 2024 production                | **1,942.50 units**                  |
| 📅 2025 production                | **2,867.00 units**                  |
| ☀️ Highest seasonal average yield | **Summer · 8.67 units**             |
| 💼 Largest operational cost       | **Labour · 96,500**                 |
| 💚 Lowest crop cost per unit      | **Sugarcane · 6.51**                |
| ⚠️ Highest crop cost per unit     | **Mustard · 47.69**                 |

### A few important observations

* Wheat produced the highest total output, but tomato had the highest yield per acre.
* Total production increased from **1,942.50 units in 2024** to **2,867.00 units in 2025**.
* Summer had the highest average yield even though Kharif had the highest total production.
* Labour represented approximately **57.3% of total operational costs**.
* Looking at production, yield and cost together gives a more complete view of crop performance than using production alone.

## 📈 Visualizations

The project includes four business-focused visualizations:

**Total Production by Crop**
Compares production across different crops.

**Yield per Acre by Crop**
Shows differences in land-use efficiency.

**Total Production by Year**
Highlights the change in production between 2024 and 2025.

**Operational Cost by Cost Type**
Shows how operational costs are distributed across major cost categories.

Column charts were selected because the main purpose of these visuals is to make category differences easy to compare.
